# TIL 블로그 운영

공개 주소: https://taypark.github.io/TIL/

## 문서 추가와 배포

1. 기존 주제 폴더에 마크다운 문서를 작성합니다.
2. 첫 번째 H1 제목을 문서 제목으로 사용합니다. 제목이 없으면 파일명이 표시됩니다.
3. 이미지 파일은 문서 기준 상대 경로로 연결합니다.
4. 문서와 이미지를 Git에 추가하고 `master`에 push합니다.
5. GitHub Actions의 `Deploy TIL blog` 실행 결과를 확인합니다.

Git에 추가한 학습 문서만 게시합니다. 미추적 파일, README, 숨김 폴더와 `site-docs/` 운영 문서는 게시하지 않습니다. 학습 문서 원본을 유지하고 웹페이지를 생성할 때 내부 링크, 이미지 경로와 제목 계층을 변환합니다. 문서 수정일은 마지막 Git 커밋 시각입니다. 최초 작성일은 추정하지 않습니다.

## 로컬 확인

Node.js 22.12 이상과 Git이 필요합니다.

```bash
npm ci
npm run build
npm run verify
npm run preview
```

미리보기 주소: http://127.0.0.1:4321/TIL/

`npm run dev`로 문서 화면을 개발할 수 있습니다. 검색 색인은 빌드 시 생성되므로 검색 검증에는 빌드 후 미리보기를 사용합니다.

## 검색과 메타데이터

- Pagefind는 문서 제목과 본문을 검색합니다. 주제 필터를 제공합니다.
- 한국어 검색은 지원하지만 조사와 어미의 변형을 자동으로 모두 처리하지 않습니다.
- title, description, canonical, Open Graph와 BlogPosting 구조화 데이터를 생성합니다.
- 기본 description은 기존 본문에서 추출합니다. 새 사실이나 AI 요약을 만들어 넣지 않습니다.
- 제목 계층, 목차, 출처 링크와 관련 문서 링크를 제공합니다.
- sitemap: https://taypark.github.io/TIL/sitemap.xml
- 검색 화면과 404 화면은 noindex로 설정합니다.

`/TIL/robots.txt`는 호스트 루트의 robots.txt를 대신할 수 없습니다. 현재 프로젝트는 루트 robots.txt를 제어하지 않습니다. 검색 수집을 막는 루트 설정이 없는지 호스트에서 확인해야 합니다.

## 검색엔진 등록

1. Google Search Console에 `https://taypark.github.io/TIL/`을 URL 접두어 속성으로 추가합니다.
2. HTML 파일 방식으로 소유권을 확인하려면 제공된 파일을 `public/`에 저장하고 배포합니다.
3. 소유권 확인 후 `sitemap.xml`을 제출합니다.
4. URL 검사에서 대표 문서의 색인 생성을 요청합니다.
5. 필요하면 네이버 서치어드바이저에도 같은 사이트를 등록합니다.

계정 로그인과 소유권 확인은 별도 접근 권한이 필요합니다. 사이트 배포나 sitemap 생성은 검색 결과 노출 또는 AI 답변 인용을 보장하지 않습니다.

## 배포 검증

빌드 검증은 게시 대상 문서 수, 문서별 H1, 메타데이터, 구조화 데이터, sitemap, 내부 링크와 로컬 자산을 확인합니다. 공개 후에는 홈페이지, 문서 직접 접속, 검색 결과 이동과 모바일 화면을 확인합니다.
