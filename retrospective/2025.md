# 2025 회고

어김없이 올해도 회고를 늦게... 쓴다. 12월 말에 쓰려고 했는데 까먹었다.

## 2024 회고를 회고하기

### 계속할 것

1. 책 읽기 - 👎
    - 작년에 문학을 좀 읽었는데, 올해는 거의 못 읽었다. 책 안 읽으니까 문해력과 단어력이 퇴화하는거 같다.
2. 세세한 계획 짜기 - 🤔
    - 작년보단 많이 나아지긴 했는데 요즘 AI 외주줘서 잘 모르겠다.

### 그만둘 것

1. 시간 낭비 👎
    - 더 늘어진 거 같다. 일에 대한 흥미도 떨어지고, 소비에만 집중한 거 같다. 커리어를 위해 뭔가를 한다기보단, 그냥 시간을 때우는 느낌이 강했다. 특히 하반기에 더.
2. 불필요한 것 하지 않기 - 🤔
     - 어느 정도는 지킨거 같다. 결국 말을 하지 않음으로 해결된 것 같은데, 그게 최선이었는지는 모르겠다.
3. 메시지 다시 읽고 전송 ✅
     - 좀 더 신경 쓴 거 같다. 메시지를 다시 보내거나 상대방이 내 의도를 다시 묻는 경우가 많이 줄어들었다.

### 새롭게 해볼 것

1. 의도적 시간 사용 - ✅
    - 조금은 된 거 같다. 아래 회고에도 쓰겠지만 덕분에 새로운 시스템을 많이 만들어냈다. 앞으로는 의도적으로 일주일에 1시간씩 비워두는걸 해보려고한다.
2. 새로운 사람 만나기 - ✅
    - 모임도 나가고, 식견이 넓어진 느낌이 났다. 다양한 분야의 사람들을 만나면서 생각지도 못한 인사이트를 얻을 수 있었다. 그러면서 비용도 많이 쓰긴했는데... 그래도 얻은것도 많은것 같다.
3. 접근성 좋은 사람 되기 ✅
    - 외적으로 노력을 했던거 같다. 기존에는 너무 공대스러운 옷과 외관이었는데(그냥 안경 끼고 다녔고...) 요즘엔 옷도 좀 사고 머리도 좀 다듬고 한다. 그래도 전보단 낫다고 생각은 한다. 아마도... 내적으로는 안 해도 될 말을 안 하려고 노력한 거 같다. 덕분에 말 수가 줄어서 I가 된 거 같기도 하다.

## 2025 회고

### 1분기

- 인앱이벤트 시스템 무중단 go migration 을 성공적으로 진행했다. 꽤 많은 비용 개선이 있었고, 무엇보다도 처리 속도가 빨라지니 전체 파이프라인이 빨라진 것이 또 하나의 성과였다.

### 2분기

- `Apache Iceberg` PoC 를 시작했다. 데이터 분석 니즈가 더 늘어났고, 현재 DW 시스템 한계가 보이기 시작했기 때문이다. 좋은 기회라고 생각해서 승낙했고, 여러 자료를 찾아보면서 공부를 시작했다. 결국 하지 않기로 했지만 현대 데이터 엔지니어링에 대해서 많이 알 수 있었다. 그리고 덜 익은 AWS 프로덕트는 안 써야겠다는 결심을 하게됐다(...)
- End to End 데이터 파이프라인 시스템을 구축했다. 타 시스템과의 인증부터 데이터 처리, 적재, 데이터 정책 수립 및 적용 등 전반적인 시스템을 설계하고 구현했다.
- Kafka Connect 를 Vector 로 교체하는 작업을 진행했다. 실시간성이 개선됐고 비용도 줄었다. Unload 를 조절할 수 있게 되면서 Snowpipe 비용도 줄었다. 그런데 요즘 새로운 문제가 생기고 있는거 같아서 어떻게 해결할지 고민 중이다.
- DW 작업들을 더 많이 하게됐다. dbt 도 적당히 써보고 Snowflake 최적화, Airflow 등등.

### 3분기

- 🏠 리프레시 휴가로 8월 3주를 쉬었다. 제주도와 후쿠오카를 다녀왔다.
- 입사했을 때부터 있던 팀장이 퇴사했다. 백엔드 그룹이 팀으로 개편되면서 그룹리드가 팀리드가 됐다. 하는 일엔 달라진게 없으나 사수가 없어진게 아쉽다.
- ❄️ 돌아오자마자 Snowflake World Tour 2025 스피커로 참여했다. Snowflake AI 를 활용하여 데이터 분석을 쉽게 할 수 있는 플랫폼을 만드는 내용이었다. 발표 준비를 하면서 Snowflake AI 에 대해 많이 알게 되었고, 발표도 잘 마무리했다.
- 서울리전 작업을 본격적으로 시작하면서 terraform 이랑 많이 친해져야만했다. 그래도 바이브코딩이 유행하면서 Cursor, Claude Code 로 생산성을 많이 올렸다.

### 4분기

- 계속 서울리전 작업을 했다. 
    - Snowflake IaC 를 했다. 멀티리전 구성하는게 훨씬 쉬워졌고, 추가 리소스를 만드는게 간단해졌다.
    - Schema Role 이라는 개념을 도입했다. 현재 조직에서는 특정 database.schema 수준으로 조회하는게 일반적이라(교차 조인은 권한자만 접근 가능) 특정 database.schema 하위에 대한 권한을 reader / writer 로 구분해서 관리할 수 있도록 했다. 덕분에 권한 관리가 훨씬 수월해졌다.
    - 이러면서 RnR 이 늘어난 것 같다. DW 파이프라인을 거의 내가 담당하게됐고, 추가적으로 운영적인 부분도 맡게됐다. 아직 가보지 못한 영역이라 어떤게 문제가 될지 잘 모르겠다. 지금 드는 생각은 공수 x2 를 x1.1 정도로만 줄이는게 목표다. 

### 2025년에 느낀 점

1. AI 활용 능력이 곧 능력이다. 유튜브, 링크드인만 보더라도 AI 얘기밖에 없다. 나중에는 AI 컨설턴트도 생기겠다 싶다. 기업 내에서 AI 를 잘 활용할 수 있도록 돕고 전체 조직이 AI 능력을 함양할 수 있도록 시스템을 만들고 운영하도록 해주는 것이 아닐까? 이런걸 생각하면 앞으로 더 AI 활용 능력을 키워야겠다는 생각이 든다.
2. 인간 관계에 대해; 단호함이 다정함이고, 거절을 두려워하지 말자. 이건 회사 안이든 밖이든 마찬가지라고 2025년에 많이 느꼈다.
3. 앞으로 저점이 높은 사람이 더 높은 점수를 받겠다는 생각이 들었다. 기초를 더 다져야겠다는 생각이 들었다. 데이터 엔지니어링, AI, 그 외 인문학적 요소들. 
4. 사람을 많이 대했지만 그만큼 성장한 것 같진 않다. 최근에 드라마 정도전의 명대사를 읽은 적이 있는데, 주기적으로 보면서 내가 어떤 사람이 돼야할지 생각해보는 시간을 가져야겠다 싶었다.
